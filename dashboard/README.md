# Power BI Dashboard

The Power BI report is stored in `olist_project.pbix`.

## Purpose

The report is intended to communicate business performance across:

- Orders and revenue trends
- Product category performance
- Seller contribution
- Delivery performance
- Payment behavior
- Customer review patterns

## Review Notes

The `.pbix` file is a Power BI Desktop binary and is not rendered as an interactive dashboard inside GitHub. Open it with Power BI Desktop to inspect the report.

Dashboard screenshots can be added to this folder later as lightweight portfolio previews. The repository should prioritize **business insights and readable visuals** over storing additional raw/exported datasets.
